# Descobertas dos agentes

Um arquivo por agente (`arquitetura.md`, `ui-ux.md`, `funcional.md`, `documentacao.md`, `audiovisual.md`,
`qa-devops.md`). Só o dono edita o próprio arquivo; pedidos para outros agentes vão como item "Pedido para <agente>".

Formato de cada entrada:

```
## AAAA-MM-DD · <agente> · <título curto>
- Descoberta:
- Evidência: (arquivo, fonte_id/chunk_id do Harness, print, log)
- Impacto:
- Próximo passo / pedido:
```
